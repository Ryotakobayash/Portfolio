## はじめに

これまでのブログとはかなり毛色が違うが、最近「双掌（SO-SHO）」という名前の自作キーボードを購入・作成した。

[エレキット 双掌(SO-SHO) - 遊舎工房](https://shop.yushakobo.jp/products/12667?srsltid=AU7gw4Xd8TVTpZHuhjRP4hfFl_ciiCmn3yqVs21zMgiYJni2z_faZzKG)

このブログでは、私が使っているキーマップを共有しつつ、普段のデザイン業務で使ってみてどうだったかをまとめておく。

目的としてはこんな感じ。

- デザイナーで分割キーボードってどうなの？と思っている人がいると思うので、私なりの考えをまとめておく。
- 遊舎工房で買うことを検討している人の、購入→使えるようになるまでの不安感をなくす。
- 私が困っていたところでつまづく人をいなくする。
- 作ったキーボードを自慢しつつ、困りごとを愚痴る。

## デザイナーで分割キーボードってどうなの？（私なりの考え）

結論から先にいうが、個人的には分割キーボードはデザイナーにとってもいい選択肢だと思う。慣れるまでのめんどくささと費用を許容できるなら、よくあるキーボードよりは良い体験を得られると思う。

分割キーボードについての議論をちょこちょこ見かけるが、しれっと前提とか、どこからくる良さなのかがごちゃまぜになっていたりする。今回は「自作キーボードの1種として作る分割キーボードの中の、双掌という商品」というふうに整理して、自作キーボードの良さと、分割キーボードの良さと、双掌自体の良さが分けて書いてみた。

### 分割キーボードとしての良さ：体の真正面にスケッチブックを置ける

一番良かったのはこれ。
左右のキーボードの間にスペースができるので、**体の真正面にスケッチブックや書籍、手帳などを置けるようになる**。

アイデア出しやワイヤーフレームのスケッチ、資料をチェックしながらのPC作業がめちゃくちゃ捗る。
普通の一体型キーボードだとノートを左右のどちらかに追いやるしかなくて身体がねじれるので、これだけでも分割にしてよかったと思えるレベル。

### 自作キーボードとしての良さ：左手への機能集約と、JIS/USのいいとこ取り

自作キーボードは大抵の場合、キーマップの書き換えが可能だ。それによりいろんな恩恵を受けることができる。

デザイナーは右手でマウスやペンを持っている時間が長いので、ショートカットを左手だけで操作できるように色々設定できるのが便利。私は十字キーやテンキー、Enter、Deleteなども左手でだけで利用できるようにしている。

あと、JISとUSキーボードのいいとこ取りができるのも良い。
特に日本語と英語の切り替え。JIS版のmagic keyboardには「英数」「かな」のボタンがあり、これを押すことで冪等に言語を切り替えることができるが、USのキーボードでは存在しなくて残念に思っていた。

それを考慮し、ベースはUS配列としつつも親指周りに言語切り替えキーを割り当てた。最高。

### 双掌の良さ：トラックボールを「左手」に置ける

ここまでの良さは他の分割キーボードにも当てはまる。
今回購入した双掌の良さはトラックボールの位置を自分で選べる点かなと思う。

世の中の分割キーボード（既製品も自作も）はそもそもマウスを使わない人向けの製品が多く、その前提で利き手（右）にトラックボールが付いていることが多い気がする。
でも私は右手でマウスやペンを持ちたい。ペンを持ちながら**左手でちょっとだけカーソルを動かしたいときに、左側にトラックボールを置ける**のが嬉しかった。ここを選べるのは双掌の大きな強みだと思う。

ちなみにくるくる回すやつ（ロータリーエンコーダー）も付いている。一応スクロールとかできるが、正直あまり使っていない。見た目のメカメカしさは好き。

## 遊舎工房で購入して、その場で組み立てた話

### 店頭で購入したパーツと選び方の注意

私は秋葉原にある遊舎工房の実店舗でキットを購入した。
店頭に試供品が置いてあったので、実際にサイズ感や打鍵感を触って最終判断できたのが良かった。

説明書を見ると購入者側で用意するパーツが色々あるが、これは全部店頭で買える。

買ったパーツと値段はこんな感じ。

- **キット本体**: エレキット 双掌(SO-SHO)（約30,000円）
- **キースイッチ**: [Kailhロープロファイルスイッチ（私は茶軸）](https://shop.yushakobo.jp/products/4266?variant=43583462375655) 90円 × 44個くらい（約4,000円）
- **キーキャップ**: chosfox MX side print low profile keycaps set smoky Gray（6,000円くらい）

注意点として、**キースイッチはCherry MX系ではない**こと。ロープロファイルのスイッチが必要。
キーキャップもロープロ用で、かつ**1uのキーキャップがいっぱいあるやつじゃないと足りなくなる**。心配なら店員さん聞いてみるのが確実だと思う。

### 工作スペースでの組み立て（30〜40分くらい）

私は遊舎工房の工作スペースを利用した。1時間1,000円。
工具類は全部揃っているので手ぶらで行ける。

細かい組み立て方については公式の組み立てガイドが優秀だったので、私から説明する必要はないと思う。ガイドに載っているYouTube動画はちゃんと見るといいですよ。

ショップ側にいる店員さんも工作スペースにいるスタッフさんも双掌の組み立てに慣れているようで、結構ツーカーでサポートしてくれた。ありがたい。余裕を持って終わったので、説明書や動画を見ながらで30〜40分くらいだったと思う。

### 【注意】バッテリーだけは家で付ける必要がある

キットの中にはバッテリーパック（リチウムポリマー電池）が入っているが、これは火事の危険性がどうこうで、遊舎工房の方針として**「バッテリーだけは工作スペースで作業できず、家で取り付ける必要がある」**とのことだった。

組み立ての順序的に**キーボード裏の蓋を閉めることができないので、結構中途半端な状態（基板半開き）で家に持って帰る必要がある**。
買ったときの袋があるので家が近いなら大丈夫だと思うが、遠出して買いに行く人や組み立て後に別の予定がある人はキットに入っている袋とか緩衝材を捨てないようにした方がいいかもしれない。

## キーマップのこだわり

最初はブラウザからGUIで設定できる ZMK Studio を使っていたが、今はキーマップの設定ファイルをGitHubで管理して、GitHub Actionsでビルドしたファームウェアを書き込む形に切り替えた。構成は5レイヤー＋コンボ。

### 各レイヤーの構成

更新した(2026/10/31)

#### Layer 0（ベースレイヤー）

通常の文字入力を行う基本レイヤー。QWERTY配列をベースにしつつ、外側や親指周りの押しやすい位置に主要なキーを寄せてある。

Aの左のキーにはダブルタップ（Tap-Dance）を仕込んでいて、一回押すと普通のCtrl、二回押して押しっぱなしにすると後述するLayer Ctrl（Emacsバインド・マクロレイヤー）に切り替わるようになっている。FigmaなどEmacsキーバインドが一部しか使えないアプリで使いたいときに便利。

親指周りは左から Esc、Option、Cmd、英数、Space、かな、Layer 3、Layer 3 の並び。英数とかなは長押しするとそれぞれLayer 2、Layer 1に切り替わる。前述した「英数」「かな」による冪等な言語切り替えはここで実現している。

ロータリーエンコーダーは、普段はスクロールに割り当てている。

![Layer 0（ベースレイヤー）のキーマップ](./20260922_so-sho/Layer0.png "Layer 0：ベースレイヤー")

#### Layer 1（ショートカット・括弧レイヤー）

かなキーの長押しで入るレイヤー。左手側には `Cmd + Option + 1〜9` をテンキーと同じ並びで置いてある。見出しの切り替えなどで使うショートカットで、数字行がないキーボードだとこれを押すのが本当に大変だったので、専用のレイヤーを作った。

右手側には `(` `)` `[` `]` を置いている。括弧は記号の中でも打つ頻度が高いので、ホームポジションの近くに寄せた。

![Layer 1のキーマップ](./20260922_so-sho/Layer1.png "Layer 1：ショートカット・括弧レイヤー")

#### Layer 2（両手テンキーレイヤー）

英数キーの長押しで入るレイヤー。数字入力を集約していて、左右どちらの手でも数字を打てるように、両側にテンキー配列を仕込んである。

左手側にもEnterとBackspaceを置いてあるので、右手でマウスを持ったまま左手だけで数値入力と確定が完結する。テンキーの左隣にはスクショ（`Cmd + Ctrl + Shift + 3 / 4` でクリップボードにコピー）のショートカットを仕込んでいる。

あと、このレイヤーのときだけ左手のエンコーダーが音量調整になる。

![Layer 2のキーマップ](./20260922_so-sho/Layer2.png "Layer 2：両手テンキーレイヤー")

#### Layer 3（ファンクション・矢印キー）

右手親指の外側2つのキーで入るレイヤー。左手側にF1〜F9をテンキーと同じ並びで置き、その左端に音量調整（Volume Up/Down/Mute）、右手側に逆T字の矢印キー（↑↓←→）を配置した。右手の上段には Bluetooth の接続先の切り替えも置いてある。

![Layer 3のキーマップ](./20260922_so-sho/Layer3.png "Layer 3：ファンクション・矢印キー")

#### Layer Ctrl（Emacsバインド・マクロレイヤー）

Ctrl系のショートカットやEmacs風の操作を集めたレイヤー。macOSのテキスト入力欄はもともとEmacs風のキーバインドが一部使えるが、アプリによって効いたり効かなかったりするので、矢印キーやCmd + ←→ に変換してどこでも同じように動くようにしている。

どのアプリでもEmacsの `Ctrl+K`（行末まで削除）が使えるように、「Cmd + Shift + → で行末まで選択して Backspace で削除する」というマクロ（`kill_line`）を `K` に仕込んである。マクロはZMK Studioの画面には表示されないので、画像では `K` の位置が空白に見えている。

![Layer Ctrlのキーマップ](./20260922_so-sho/LayerCtrl.png "Layer Ctrl：Emacsバインド・マクロレイヤー")

#### コンボ：左右どちらの手でもクリックできる

レイヤーとは別に、2つのキーを同時押しするとマウスクリックになるコンボも設定している。

- 左手：S + D で左クリック、D + F で右クリック、S + F でホイールクリック
- 右手：J + K で左クリック、K + L で右クリック、J + L でホイールクリック

左手のトラックボールでカーソルを動かして、そのまま左手でクリックまでできる。右手にペンを持っているときに地味に便利。

### キーマップの書き換え方：GitHub Actionsでファームウェアをビルドする

ZMK StudioはGUIで手軽にキーを入れ替えられるが、マクロやコンボ、タップダンスの追加はできず、ファームウェア（`.keymap` ファイル）を直接編集する必要がある。GUIとファイルの2箇所で設定を持つと、どれが最新なのかわからなくなるので、最終的にファイル側に一本化した。

やり方はこんな感じ。

1. エレキット公式の `unified-zmk-config-template` を自分のGitHubアカウントにフォークする
2. `config/sosho.keymap` を編集して、GitHubにpushする
3. GitHub Actionsが自動でファームウェア（`.uf2` ファイル）をビルドしてくれるので、ArtifactsからZIPでダウンロードする
4. キーボードのマイコン（XIAO nRF52840）をUSBでPCにつなぎ、リセットボタンをダブルタップする
5. USBドライブとしてマウントされるので、`.uf2` ファイルをドラッグ＆ドロップする

自分が作ったファームウェアを使う以外、書き込む手順などは作るときと一緒。ビルド設定（`build.yaml`）にはトラックボール版・トラックパッド版の両方と、設定リセット用のファームウェアが入っているので、自分の構成に合ったものを選べばいい。

注意点として、ZMK Studioで変更した設定はキーボード本体に保存されていて、ファームウェアを書き換えてもそちらが優先される。Studioで触ったことがある場合は、一度設定リセット用のファームウェア（`settings_reset`）を書き込むか、Studio側で設定を初期化しておかないと、`.keymap` の変更が反映されなくて混乱する。

ZMK独特のDeviceTree記法はとっつきにくいが、AI（Antigravity）にドキュメントを渡してコードを書いてもらった。設定がテキストファイルになっていてGitで差分も残るので、「このコンボを足して」「Ctrlをタップダンスにして」とお願いしてpushするだけで済む。自作キーボードのカスタマイズとAIの相性はかなり良いと思う。

## 使ってみて感じた不満（愚痴）

使ってみてわかった微妙なところ、困りごとも愚痴っておく。

### 数字をテンキーオンリーにしたのでショートカットの難易度が爆上がりした（対策済み）

数字キーの行をなくしてテンキーレイヤーに入れたせいで、記号や数字を使うショートカットの難易度がめちゃくちゃ上がった。「Cmd + Option + 1~3（見出し1〜3）」などを押そうとすると指の体操状態になり、結構ストレスだった。

これは前述のLayer 1で、`Cmd + Option + 1〜9` をそのまま1キーで押せるようにして回避した。修飾キーと数字を同時に押さえるのではなく、かなキーを長押しして1キー押すだけになったので、だいぶ楽になった。ほかにも数字絡みのショートカットで困ったら、同じようにショートカットごとレイヤーに置いてしまえばいいと思う。

### 親指キーが少ない＆タップダンスの誤タイプ

双掌の設計上、親指で押せるキー数が少ない。その辺の自由度が低い分、他のキーにしわ寄せがいっている。
選択肢を増やすためにタップダンス（キーを単押しするか長押しするかで挙動を変える機能）やレイヤー切り替えを使うわけだが、これがタイピング時の誤タイプのもとになる。あとキー数が少ないのでキーの割り当て自体がパズルでめんどくさい。

### トラックボールの滑りが悪い（多少改善はする）

トラックボールモジュールの滑りが最初はかなり悪かった。しばらくグリグリ触ってみて、抵抗があるところを削ったりなんなりして調整した。
最初は「**トラックボールの抵抗 ＞ 机との摩擦抵抗**」となって、トラックボールを回そうと思ったらキーボード本体が机の上を移動していって面白かった。付属のキーボード裏につける滑り止めシールを貼ると意外となんとかなる。

使っていけばどんどんマシになっていくが、それでもlogicoolとかで買えるトラックボール付きマウスほどのクオリティにはならないので、あくまでカーソル移動の補助用と割り切るのが吉。

### 大部分が3Dプリンター製なので構造として弱い

板材っぽいところもメネジ（ネジ穴）部分も全部3Dプリンター製。
結構慎重に組み立てないといけないし、ネジを締めすぎると割れそうで、組み立て時も使っている時も常に素材に対する不安が付きまとう。
