# ブログ記事 執筆・画像管理ワークフロー

本サイト（Astro 7 + Content Collections）における新しいブログ記事の作成方法、ファイル・画像の命名規則と配置方針、Markdown記法、および公開チェックリストをまとめたドキュメントです。

---

## 1. 記事作成のクイックスタート

記事の雛形作成には、専用のスクリプトコマンドを用意しています。

```bash
# 対話形式で作成（タイトル・スラッグ・タグを質問）
pnpm new:post

# タイトルを直接指定して作成
pnpm new:post "Webフォントの勉強会に参加してきました"

# スラッグやタグも指定して作成
pnpm new:post "Webフォントの勉強会" --slug "webfont-study" --tags "Web,Font"
```

### コマンド実行時に自動で行われること
1. **日付の自動解決:** 本日の日付（JST基準）を取得し、`YYYY-MM-DD`（Frontmatter用）と `YYYYMMDD`（プレフィックス用）を算出。
2. **記事ファイルの生成:** `src/content/posts/YYYYMMDD_<タイトルまたはスラッグ>.md` を作成。
3. **画像フォルダの生成:** `src/content/posts/YYYYMMDD_<スラッグ>/` を自動作成（`.gitkeep` 同梱）。
4. **Frontmatter & ガイドコメントの挿入:** スキーマに適合した Frontmatter と、画像の貼り方ヒントが記事冒頭に埋め込まれます。

---

## 2. ディレクトリ構成と命名規則

### ファイル・フォルダ構成
記事ファイルと画像フォルダは、すべて `src/content/posts/` 直下にペアで配置します。

```text
src/content/posts/
├── 20260706_Webフォントの勉強会に参加してきました.md      # 記事本文
├── 20260706_webfont-study-2026/                        # 当該記事専用の画像フォルダ
│   ├── image-1.png
│   └── architecture.jpg
```

- **記事ファイル:** `YYYYMMDD_<タイトルまたはslug>.md`（日本語タイトル可）
- **画像フォルダ:** `YYYYMMDD_<英語slug>/`（URLや相対パスでの参照を考慮し、半角英数字ハイフンを推奨）

---

## 3. Frontmatter (メタデータ) の仕様

`src/content.config.ts` で定義されたスキーマに従います：

```yaml
---
title: "記事のタイトル"
date: "2026-09-22"         # YYYY-MM-DD 形式（必須）
excerpt: "記事一覧カード等に表示される要約文（任意）"
tags:                      # タグ一覧（配列）
  - "Tech"
  - "Astro"
draft: true                # 執筆中は true、公開時に false または行削除
---
```

> [!IMPORTANT]
> **未公開記事の Git 管理について**  
> `draft: true` で執筆中の記事ファイルは、公開準備ができるまで Git コミットに含めない運用としています（AI エージェントも明示的な指示がない限りコミットしません）。

## 4. 画像の保管・Markdown 記法ルール

画像の自動最適化（WebP変換・リサイズ）および図表番号の自動ナンバリングを行うため、以下のルールを遵守します。

### 画像の参照方法
画像フォルダへの相対パス（`./YYYYMMDD_slug/画像名.ext`）で指定します。

```markdown
![スクリーンリーダー用代替テキスト](./20260706_webfont-study-2026/diagram.png "画面に表示する図表タイトル")
```

### 図表タイトルと代替テキストの役割分担
[`src/components/CustomImage.astro`](../src/components/CustomImage.astro) により、上記記法は以下のようにレンダリングされます：

1. **`"画面に表示する図表タイトル"`（末尾のダブルクォート部分）:**
   - 画像の下部に `<figcaption>` として表示されます。
   - CSS カウンタによって **「図1: 画面に表示する図表タイトル」** のように、自動的に記事内の連番が付与されます。
2. **`![スクリーンリーダー用代替テキスト]`（角括弧部分）:**
   - スクリーンリーダー等に読まれる代替テキスト（`alt` 属性）として保持されます。
   - ※ タイトルを省略した場合は、フォールバックとしてこの `alt` がキャプションとして表示されます。
3. **サイズ自動制御:**
   - 縦長すぎる画像が画面全体を埋め尽くさないよう、CSS で `max-height: 60vh` かつ中央配置（`object-fit: contain`）が適用されます。

## 5. 公開前のセルフチェックリスト

記事を公開（`draft: false` または削除）して Push する前に、以下の確認を行ってください。

- [ ] **Frontmatter の日付とフォーマット**
  - `date` が `YYYY-MM-DD` 形式になっているか
  - `tags` が配列形式になっているか
- [ ] **開発サーバーでの表示確認 (`pnpm dev`)**
  - `http://localhost:4321/posts`（記事一覧）にカードが表示されるか
  - 記事詳細ページで画像が正常にロードされ、図表番号（図1: ...）が表示されているか
  - 目次や脚注が正しく機能しているか
- [ ] **プロダクションビルドの確認**
  ```bash
  pnpm build
  ```
  - 型エラーやビルド破損がないことを確認
- [ ] **公開設定への切り替え**
  - Frontmatter の `draft: true` を削除、または `false` に変更する
